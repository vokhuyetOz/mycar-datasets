# mycar-datasets

Service directory for the MyCar app (repair shops, roadside help, car washes, EV charging, fuel, parking), one file per country.

- `index.json`: latest version, file, SHA-256 and row count per country (ISO 3166-1 alpha-2).
- `places/<CC>.<version>.bin`: 16-byte IV + AES-256-CBC (PKCS7) of a zip holding `places.tsv`; key = SHA-256 of the app id.
  This only keeps the data out of plain sight.

Data: © OpenStreetMap contributors (ODbL 1.0, https://www.openstreetmap.org/copyright) and official operator pages;
each row keeps its source. Generated by `scripts/publish_places.py` in the app repo. Mirror: rustfs-server.nihontechhub.com.
